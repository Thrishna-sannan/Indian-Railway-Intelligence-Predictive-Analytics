# 🚆 Indian Railway Intelligence

### Railway Predictive Analytics Using Machine Learning

## 📌 Project Overview
Indian Railway Intelligence is a predictive analytics project developed using Python and Machine Learning. It analyses Indian railway station data to explore station distribution, railway zones, route connectivity and junction status.

## 🎯 Objectives
- Analyse railway station distribution across Indian states.
- Explore railway zone-wise distribution.
- Identify stations with higher route connectivity.
- Visualise station locations across India.
- Predict Junction and Non-Junction station status.

## 📊 Dataset
- Total Records: 8,990
- Geographic Coverage: 36 states and territories.
- Target Variable: `is_junction`

## 🤖 Machine Learning Models
1. Logistic Regression
2. Linear Regression
3. K-Nearest Neighbors (KNN)
4. Random Forest

## 📈 Dashboard Features
- Total Stations KPI
- States Covered KPI
- Junction Stations KPI
- Total Route Count KPI
- Station Network Map
- Junction vs Non-Junction Analysis
- Railway Zone Distribution
- Top 12 States by Station Count
- Top 15 Stations by Route Connectivity
- Searchable Station Explorer
